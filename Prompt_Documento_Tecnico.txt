Contexto del proyecto:

Soy desarrollador de un sistema web llamado MaquinadosRBS, un Sistema de Gestión de Calidad para una empresa de maquinados industriales. El stack tecnológico es:

- Frontend: React 18.2 (CRA), React Router DOM 6.21, CSS vanilla (sin frameworks UI), sin TypeScript.
- Backend: Express 4.21, SQLite (better-sqlite3), JWT para autenticación, Multer para subida de archivos.
- Patrón de API: Todas las llamadas HTTP se centralizan en src/services/api.js usando fetch nativo con una función request() genérica que maneja headers de autorización JWT y serialización JSON. Los contextos de React (AuthContext, RevisionsContext) consumen estas funciones con useCallback y manejan estados booleanos de loading.
- Estado actual de loading: Todos los estados de espera se manejan exclusivamente con texto plano ("Cargando...", "Ingresando...", "Guardando..."). No existen spinners animados, skeleton screens, ni shimmer effects en todo el proyecto.
- Manejo de DOM: Solamente se usan handlers estándar de React (onClick, onChange, onSubmit). No hay event listeners manuales, ni useRef para acceso DOM, ni eventos onMouseEnter/onMouseLeave en JSX. Los hover effects existen únicamente en CSS (:hover).
- Componentes principales: SplashScreen, Login, Layout (Header + Sidebar + Outlet), Dashboard con RevisionsTable, NewEntryForm (modal), PieceDetailModal (modal con tabs: Info, Plano, Inspección), QualityInspectionForm (tabla editable de operaciones), ClientView, SearchBar (actualmente con datos mock).
